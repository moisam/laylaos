This folder contains QT-based desktop applications. Most of these are 
cross-platform, with a few exceptions that require platform-specific
low level interaction with the gui server (the keyboard app, the
color theme changer, the desktop background app, the desktop wallpaper
and bottom panel).

Applications in this folder use icons that come from the following
sources, all of which are released under a public license:

- https://icon-icons.com/authors/362-arthur-zaynullin

  calculator, calendar, clock, paint, system theme, system info

- https://icon-icons.com/authors/10-icons8

  editor & screenshot

- https://icon-icons.com/authors/550-papirus-development-team

  files, video player, pdf viewer, process monitor, archiver, terminal, keyboard

- https://icon-icons.com/pack/colocons-free/1808

  image viewer & system display

- https://icon-icons.com/authors/1237-carbon-design

  font viewer

- https://icon-icons.com/authors/959-panca-okta

  desktop EXE icon

- https://icon-icons.com/authors/1131-a

  battery widget icons

- https://icon-icons.com/authors/215-benjsperry

  volume widget icons (inverted)

- https://icon-icons.com/authors/115-icon-icons-carlos

  settings & cursor viewer
